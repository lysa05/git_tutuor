# Мини-трекер задач

Небольшой учебный проект для практики Git. Программа хранит задачи в JSON-файле и умеет показывать, добавлять и завершать их.

## Запуск

Нужен Python 3.9 или новее.

```bash
python3 app.py list
python3 app.py add "Изучить git status"
python3 app.py done 1
```

По умолчанию задачи сохраняются в `tasks.json`.

## Проверка

```bash
python3 -m unittest discover -s tests -v
```

## Идеи для упражнений в Git

1. Сделать первый коммит с исходным проектом.
2. Создать ветку `add-priority` и добавить приоритеты задач.
3. Создать ветку `improve-help` и улучшить справку команд.
4. Изменить одну и ту же строку в обеих ветках и потренироваться решать конфликт.
5. Посмотреть историю через `git log --oneline --graph --all`.
6. Отменить безопасное изменение с помощью `git revert`.

Не добавляйте реальные секреты и большие файлы в этот репозиторий.
